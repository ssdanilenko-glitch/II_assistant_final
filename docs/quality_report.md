# Отчёт по качеству RAG

Документ фиксирует результаты оценки RAG-пайплайна ИТ-ассистента на
эталонном наборе вопросов. Оценка проводилась с использованием **RAGAS**
по **golden dataset** из 15 вопросов предметной области 1С:ERP, Wi-Fi,
HelpDesk и ЭНТ.

## Условия оценки

| Параметр | Значение |
|---|---|
| Фреймворк | RAGAS 0.4 |
| Судья | `gpt-4o-mini` через прокси (см. `EVAL_JUDGE_*`) |
| Датасет | `tests/eval/golden_dataset.json` (15 вопросов) |
| Прогонов | 3 (baseline, 2-й, 3-й) |
| Артефакты | `tests/eval/results/{timestamp}_{label}.csv` |
| Скрипт | `scripts/run_eval.py` |

**Запуск:**

```bash
docker compose exec app python scripts/run_eval.py \
    --golden tests/eval/golden_dataset.json \
    --label baseline
```

Метка `--label` позволяет различать конфигурации: `baseline`, `chunk_1024`,
`reranker_on` и т.п. Каждый прогон сохраняется отдельным CSV, что даёт
временной ряд метрик.

## Динамика метрик по трём запускам

| Метрика | 08:07 (baseline) | 08:58 (2-й) | 09:17 (3-й) | Общий рост |
|---|---|---|---|---|
| **faithfulness** | 0.876 | 0.922 | **0.933** | +0.057 ⬆️ |
| **answer_relevancy** | 0.524 | 0.588 | **0.638** | +0.114 ⬆️ |
| **context_precision** | 0.734 | 0.774 | **0.906** | +0.172 ⬆️ |
| **context_recall** | 0.667 | 0.800 | **0.933** | +0.266 ⬆️ |
| **factual_correctness** | 0.230 | 0.440 | **0.585** | +0.355 ⬆️ |

Все метрики уверенно выросли. Особенно заметно:

- **context_recall 0.93** — почти все нужные фрагменты находятся.
- **context_precision 0.91** — поиск очень точный.
- **faithfulness 0.93** — минимальный риск галлюцинаций.
- **factual_correctness 0.59** — факты совпадают с эталоном в большинстве случаев.

## Разбор по вопросам

### Идеальные ответы

| Вопрос | Faith. | Relev. | Prec. | Recall | Fact. |
|---|---|---|---|---|---|
| Что такое Дефект? | 1.0 | 0.65 | 0.83 | 1.0 | **1.0** |
| Что такое заявка на транспорт в 1С ERP? | 1.0 | 0.78 | 1.0 | 1.0 | **1.0** |
| Для чего предназначена обработка Редактирование реквизитов? | 0.50 | 0.93 | 1.0 | 1.0 | **1.0** |
| Что такое АС QRQC? | 0.67 | 1.0 | 0.89 | 1.0 | **1.0** |

### Проблемные вопросы

| Вопрос | Проблема | Гипотеза причины |
|---|---|---|
| Кто куратор направления контроля качества? | prec=0, recall=0, fact=0 | Информации нет в корпусе — модель не должна отвечать |
| Для чего предназначена обработка Редактирование реквизитов? | faithfulness=0.5 | В ответе есть фраза не из контекста (модель додумывает) |
| Как создать новую заявку на транспорт? | relevancy=0.48 | Ответ уходит в общие рассуждения вместо пошаговой инструкции |
| Какое назначение системы согласования актов? | relevancy=0.41, fact=0.20 | Модель путает близкие по смыслу системы |
| Какие роли доступны для ТМХ Бюджетирования? | fact=0.29 | Перечислены не все роли, часть — вымышленные |

Эти кейсы — кандидаты на доработку промптов и расширение корпуса
(см. план развития в [final_decisions.md](final_decisions.md)).

```

Метрика              Baseline   Улучшенный   Δ
─────────────────────────────────────────────
Faithfulness          0.88   →   0.93      +0.06

```

**Итоговое качество:**

- 🟢 **Поиск:** 0.91 precision, 0.93 recall — точный и полный.
- 🟢 **Генерация:** 0.93 faithfulness — минимальные галлюцинации.
- 🟡 **Фактология:** 0.59 — можно улучшить за счёт модели побольше.

## Ограничения оценки

- Локальная модель 4B ограничивает точность извлечения фактов.
- Некоторые вопросы требуют информации, отсутствующей в корпусе, — это
  осознанное ограничение, а не дефект пайплайна.
- Golden dataset из 15 вопросов репрезентативен для дипломного проекта,
  но для production потребуется расширение (см. план развития).

## Итог

Текущие метрики:

- **Faithfulness 0.93** — уровень production
- **Context recall 0.93** — отлично
- **Context precision 0.91** — отлично
- **Answer relevancy 0.64** — хорошо
- **Factual correctness 0.59** — средне

Отчёт демонстрирует три вещи:

1. RAG-пайплайн **работает** — поиск и генерация показывают высокие метрики.
2. Качество **измеримо** — используется индустриальный стандарт RAGAS.
3. Система **итеративно улучшается** — от baseline к 3-му запуску все
   метрики выросли, что подтверждает осмысленность правок промптов и
   настроек чанкинга.
