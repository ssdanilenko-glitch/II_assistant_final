# Векторное хранилище Qdrant

## Общее описание

В рамках дипломного проекта реализовано векторное хранилище на базе
**Qdrant** для семантического поиска по корпусу документов ИТ-поддержки
АО «УК «БМЗ».

- Коллекция: `rag_block_04`
- Модель эмбеддингов: **`BAAI/bge-m3`** (размерность **1024**, мультиязычная)
- Режим: `COSINE` по метрике расстояния
- Загрузка данных идемпотентна (`stable_id` по `source` + `chunk_index`)
- Поиск поддерживает фильтрацию по метаданным (`source`, `chunk_index`)

Сервисная обёртка — `app/services/vector_store.py` (async-клиент
`qdrant_client.AsyncQdrantClient`). Индексация выполняется в
`app/services/ingestion.py`.

---

## 1. Метрика близости

**Выбор:** `COSINE`.

**Обоснование:**

- BGE-M3 возвращает **L2-нормализованные** векторы, поэтому косинусное
  расстояние и скалярное произведение дают идентичное ранжирование top-K.
- `COSINE` устойчива к масштабированию векторов: если модель в будущем
  заменят на ненормализованную, метрика останется корректной, а `DOT` — нет.
- Значение лежит в диапазоне `[-1, 1]`, что удобно для порога
  `RAG_SCORE_THRESHOLD`.
- `COSINE` — де-факто стандарт для семантического поиска.

### Сравнение COSINE и DOT (эксперимент)

точки из реальной коллекции `rag_block_04`, клонирует их в две временные
коллекции с метриками `COSINE` и `DOT`, прогоняет запросы из golden dataset
через BGE-M3 и сравнивает top-5.

- Корпус: 668 точек (`rag_block_04`)
